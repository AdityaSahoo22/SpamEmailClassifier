OUR MISSION

Why We Built SpamGuard

Email spam is one of the most persistent threats in digital communication. From phishing attacks to fraudulent offers, spam emails waste time and put users at risk.

SpamGuard was built to solve this problem using modern machine learning — making spam detection fast, accurate, and accessible to everyone.

  • Trained on thousands of real-world spam and ham emails
  • NLP preprocessing with stemming and stopword removal
  • Bigram TF-IDF features for better pattern recognition
  • Screenshot OCR support for image-based emails
  • Secure user accounts with hashed passwords
TECHNOLOGY

What Powers SpamGuard

A modern full-stack application built with industry-standard tools.

Python & Flask

The backend is built with Python and Flask, providing a lightweight and fast web server for the classification API.

Naive Bayes + TF-IDF

Multinomial Naive Bayes classifier with bigram TF-IDF vectorization achieves 96% accuracy on the test set.

NLTK NLP

Natural Language Toolkit handles tokenization, stemming, and stopword removal to clean and normalize email text.

MongoDB

User accounts and prediction history are stored in MongoDB, providing flexible and scalable NoSQL storage.

Tesseract OCR

Pytesseract extracts text from email screenshots, allowing classification of image-based spam emails.

Secure Auth

SHA-256 password hashing, Flask sessions, and duplicate detection keep user accounts safe and secure.

UNDER THE HOOD

How Classification Works

From raw email text to a spam verdict in milliseconds.

1. Input

User pastes email text or uploads a screenshot. OCR extracts text from images automatically.

2. Preprocessing

Text is lowercased, tokenized, stopwords removed, and words are stemmed using Porter Stemmer.

3. Vectorization

Cleaned text is converted into a numerical TF-IDF feature vector with 5000 unigram and bigram features.

4. Classification

The Naive Bayes model predicts spam or ham and returns a confidence probability score.

5. Result

An animated popup displays the verdict with a confidence bar. The result is saved to your history.
